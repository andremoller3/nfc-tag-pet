3D PRINTING

Como Importar os SVGs no Bambu Studio

1

Nomeação 1:1 Sem Confusão

Cada arquivo é nomeado exatamente com o ID da tag (ex: PET-001.svg). Você nunca precisa adivinhar qual QR pertence a qual coleira.

2

Importar no Bambu Studio

No fatiador, clique com o botão direito na mesa ou na peça base: Adicionar Peça > SVG (ou Add Modifier / Geometry).

3

Espessura de Camada Recomendada

Defina a altura do relevo do QR Code para 0.40mm a 0.60mm (equivalente a 2 ou 3 camadas de 0.20mm). Isso garante leitura rápida com câmeras de celular e resistência mecânica.

4

Contraste e Troca de Cor (AMS ou Pausa)

Use cores com alto contraste: base branca com QR preto, ou base clara com QR escuro. Evite cores translúcidas que possam atrapalhar a câmera óptica.

DEPLOY

Como Subir para o Git e Vercel

1. Subir para o GitHub

git add . git commit -m "feat: Central de produção e gerador de QR SVG" git remote add origin https://github.com/SEU-USUARIO/nfc-tag-pet.git git branch -M main git push -u origin main

2. Conectar e Publicar na Vercel

  1. Acesse vercel.com e clique em Add New > Project.
  2. Importe seu repositório nfc-tag-pet do GitHub.
  3. As configurações são detectadas automaticamente com o vercel.json incluído.
  4. Clique em Deploy. Seu gerador estará no ar em segundos!

3. Usar pelo Terminal (CLI)

npm install node gerar-producao.js lote-tags.csv
